One action
Every state has exactly one ink button in the hero and one in the header, pointing at the same place.
Headline sells, row knows
For known waitlist states the marketing headline stays and only the action row changes. Only submitted, invited and member replace the headline.
Quiet by rank
Early Access state uses the hairline pill, no lime. Lime appears only on the eyebrow dot, invite-ready and the Founding pill.
No false access
"Request" never "Start". No state before "Invited" mentions a dashboard, except to say there isn't one yet.
Mobile
Headline ≤ 3 lines at 38px. Input and button stack full-width at 54px. Header keeps a single compact state control.
Unknown state
If status can't be read (expired cookie), fall back to Visitor. Never show a broken or stale status.
* "priority" is not yet a status in waitlist.schemas.ts. Design assumes it will be added.
