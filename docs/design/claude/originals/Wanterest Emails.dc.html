6Rationale
One action. The ink button is the only filled object in the email.
Lime appears once, as a 6px dot after the wordmark. Early Access is the quietest tier, so no pill and no number yet.
Headline in Archivo with Helvetica/Arial fallback; body always Arial. Looks right even with no web fonts.
"What happens next" answers the no-dashboard question before anyone emails support.
Security copy is present but smallest on the page, and a raw link fallback covers blocked buttons.

10Implementation notes
1Send with Resend html + text, both required. From: Wanterest <access@wanterest.com>.
2Replace variables server-side and HTML-escape first_name (the current service already uses escapeHtml).
3Logo: Option B (text) is live by default. To switch, host a 240×48 PNG and uncomment Option A.
4Outlook desktop gets a VML rounded button. Everything else gets the padded <a>. Both are 52px tall, and mobile goes full width.
5No unsubscribe block: this is a required transactional email. Keep marketing sends on a separate stream.
6Test in Litmus or Email on Acid: Gmail web/iOS, Outlook 2016/365, Apple Mail, dark-mode inversion.
